# RITUAL — Barber Studio

Demo ficticia de barbería creada con HTML, CSS y JavaScript. No corresponde a un negocio real; los precios y servicios son ilustrativos.

Se publicará como sitio estático en Render.

Para personalizar para un cliente, reemplaza `config.js` (nombre, servicios, horarios, ubicación, WhatsApp), quita el modo demo solo después de verificar los datos, y utiliza únicamente imágenes autorizadas.
